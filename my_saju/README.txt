MY SAJU 1.1 - PC용 사주 명리 분석실
====================================

[실행 방법]
1. ZIP 파일을 Windows PC에서 원하는 폴더에 압축 풉니다.
2. Python 3.10 이상을 설치합니다. 설치 화면에서 Add Python to PATH를 체크하는 것을 권장합니다.
   다운로드: https://www.python.org/downloads/
3. 압축을 푼 my_saju 폴더 안의 start.bat을 더블클릭합니다.
4. 첫 실행은 인터넷 연결 상태에서 필요한 라이브러리를 자동 설치합니다.
5. 브라우저에서 http://127.0.0.1:5000 주소가 열리면 사용하면 됩니다.
6. 종료할 때는 실행 중인 검은 창에서 Ctrl+C를 누릅니다.

[포함 기능]
- 양력 및 음력 생년월일 입력, 음력 윤달 선택
- 절기 기준 사주 원국(년주/월주/일주/시주)
- 천간·지지, 지장간, 십성 표시
- 오행 분포 숫자 및 막대 시각화
- 일간 오행 입문용 해석 노트
- 성별 및 연간 음양 기준 대운 방향·기산·8단계 표시
- 인물 보관함: 입력 정보 저장, 불러오기, 삭제
- 두 사람 일간 오행 간단 비교
- 인쇄 및 브라우저 PDF 저장
- 로컬 SQLite 데이터베이스 사용

[데이터 및 개인정보]
- 저장 데이터는 프로그램 폴더 안의 saju_people.db에 보관됩니다.
- 외부 서버로 출생 정보가 전송되지 않습니다. 웹 화면은 PC 내부(127.0.0.1)에서만 열립니다.
- 폴더를 다른 PC로 복사할 때 인물 정보도 옮기려면 saju_people.db 파일을 함께 복사하세요.

[정확도와 해석의 한계]
- 간지·절기·음력 변환은 lunar-python 라이브러리를 사용합니다.
- 출생지에 따른 진태양시 보정은 적용하지 않았습니다.
- 태어난 시간을 비워두면 시주는 미상으로 표시합니다. 단, 대운 기산 계산에는 정오를 임시 사용하므로 실제 출생 시각에 따라 기산 시점이 달라질 수 있습니다.
- 오행 그래프는 천간과 지지의 겉글자만 단순 집계합니다. 지장간, 계절, 통근, 합충형파해 등을 종합한 신강·신약 또는 용신 판정이 아닙니다.
- 일간 해석은 전통 명리학의 상징을 소개하는 입문용 문구이며 개인의 성격이나 미래를 확정하는 진단이 아닙니다.
- 궁합은 일간 오행을 비교하는 간단 참고 기능입니다. 두 사람의 전체 원국을 종합한 전문 궁합 분석이 아닙니다.
- 운세는 전통문화·오락·자기성찰을 위한 참고 자료입니다. 건강·재정·법률·진로 등 중요한 결정을 대신하지 않습니다.

[문제 해결]
- Python이 없다는 메시지: Python 3.10 이상 설치 후 PC를 재시작하고 start.bat을 다시 실행하세요.
- 라이브러리 설치 실패: 인터넷 연결을 확인한 뒤 start.bat을 다시 실행하세요.
- Python 버전 문제: my_saju 폴더 안의 .venv 폴더를 삭제하고 start.bat을 다시 실행하세요.
- 실행 중 검은 창을 닫으면 서버가 종료됩니다.
