테스트 체크리스트

[프로그램 기본 테스트]
1. start.bat 실행 후 브라우저에서 http://127.0.0.1:5000 접속
2. 예시 입력: 이름 테스트 / 2000-01-07 / 12:00 / 남성 / 양력
3. 년주·월주·일주·시주 4개가 표시되는지 확인
4. 음력 날짜, 지장간, 지장간 십성, 오행, 대운 8단계가 표시되는지 확인
5. 인물 저장 → 인물 보관함 → 불러오기 및 삭제 확인
6. 인쇄 / PDF 저장 확인
7. 음력 선택 후 2023-02-30 같은 날짜와 윤달 옵션으로 변환이 되는지 확인

주의: 음력 날짜 예시는 라이브러리에서 해당 연도·월에 실제 윤달이 존재하는지에 따라 유효 여부가 결정됩니다.
